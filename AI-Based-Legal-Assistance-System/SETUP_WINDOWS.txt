AI-Based Legal Assistance System - Windows setup

1. Open PowerShell in this project folder.
2. Install dependencies:
   py -m pip install -r requirements.txt
3. Set your Gemini API key for the current PowerShell window:
   $env:GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
4. Start the app:
   py app.py
5. Open the localhost URL shown by Flask (normally http://127.0.0.1:5000).

Important:
- Do not paste your API key into app.py or commit it to GitHub.
- If Gemini is temporarily busy, the app retries and then automatically tries fallback Gemini Flash models.
- If all Gemini models are unavailable, the built-in legal knowledge base still returns an answer.
